# @jvavscratch/cli

Command-line interface for Jvavscratch project, providing easy-to-use commands for project conversion.

## Features

- Command-line project conversion
- Project management utilities
- Tree scanning for JavaScript files

## Installation

```bash
npm install -g @jvavscratch/cli
```

## Usage

```bash
jvavscratch convert <input-dir> <output-file.sb3>
```
